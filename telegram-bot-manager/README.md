# 🤖 Telegram Bot Manager

Сервис для управления Telegram-ботами, который позволяет пользователям подключать своих ботов, отслеживать подписчиков и делать массовые рассылки. Идеально подходит для владельцев небольших ботов, которым нужен простой интерфейс управления.

## ✨ Функциональность

### Основной функционал (ТЗ)
- ✅ Регистрация и авторизация пользователей (Laravel Breeze)
- ✅ Главная страница с описанием сервиса (доступна всем)
- ✅ Dashboard для авторизованных пользователей
- ✅ Добавление Telegram-ботов по токену от @BotFather
- ✅ Автоматическая настройка вебхука через пакет defstudio/telegraph
- ✅ Просмотр списка добавленных ботов
- ✅ Страница управления конкретным ботом (/bots/{id})
- ✅ Отслеживание подписчиков (кто написал боту)
- ✅ Удаление подписчиков (эмуляция блокировки/отписки)
- ✅ Массовая рассылка сообщений всем подписчикам
- ✅ Обработка команд бота: /start и /ping (логгирование информации в файл)
- ✅ Очереди (Jobs) для рассылки, чтобы страница не зависала

### 🎁 Бонусный функционал
- ✅ Поддержка отправки файлов в рассылках (изображения, документы, видео)
- ✅ AJAX-отправка рассылок без перезагрузки страницы
- ✅ Валидация токена Telegram (проверка формата)
- ✅ Пагинация списка подписчиков
- ✅ Автоматическое удаление подписчиков, заблокировавших бота
- ✅ Красивый UI на Tailwind CSS (стандартные компоненты Breeze)

## 🛠 Технологический стек

- **Backend:** PHP 8.2+, Laravel 11
- **Frontend:** Blade, Tailwind CSS (из Breeze)
- **База данных:** MySQL / SQLite
- **Очереди:** Laravel Database Queue (таблица jobs)
- **Telegram API:** defstudio/telegraph
- **Аутентификация:** Laravel Breeze

## 📋 Требования к окружению

- PHP >= 8.1
- Laravel 10 или 11
- Composer
- Node.js & NPM
- MySQL / SQLite
- Доступ в интернет (для регистрации вебхуков)
- Telegram аккаунт (для создания ботов)
- Laravel Breeze (для старта авторизации)
- Tailwind CSS (уже идет с Breeze)
- Пакет defstudio/telegraph (для работы Telegram Bot API)
- Telegram для создания ботов через BotFather
